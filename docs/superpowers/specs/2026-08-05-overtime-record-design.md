# 加班记录页面设计规格

## 目标

提供一个单页工作台，用于记录加班日期、加班时长、是否打车、打车费用和备注。数据仅保存在当前浏览器的 `localStorage` 中。

## 页面结构

- 顶部：标题“加班记录”、当前月份、右侧“新增记录”按钮。
- 汇总区：本月加班天数、累计时长、打车总费用。
- 主内容区：左侧新增/编辑表单，右侧按日期倒序排列的记录列表。
- 移动端：表单位于列表上方，汇总指标采用响应式两列布局。

## 视觉系统

- 深墨绿色背景、暖浅色内容区、橙色强调色。
- 细边框、轻微阴影、有限圆角，强调工作工具的清晰度和可扫描性。
- 中文无衬线字体；数字使用醒目的半等宽视觉。
- 使用图标表达日期、时长、车辆、编辑和删除等明确操作。

## 交互和数据

- 日期默认填充今天；时长以小时录入，支持小数。
- “打车回家”关闭时，费用字段禁用并保存为 `0`。
- 费用必须为大于等于 `0` 的数字。
- 新增和编辑复用同一表单；保存后清空并显示成功反馈。
- 删除前需确认；列表为空时显示引导空状态。
- 数据结构：`{ id, date, hours, tookTaxi, taxiCost, note }`。

## 验证

- 验证新增、编辑、删除、汇总计算和 `localStorage` 持久化。
- 验证打车开关与费用字段联动、表单校验、空状态。
- 验证桌面端和移动端布局，无横向溢出。
